## ✨ Overview

Aleltu is a powerful and highly secure POS system designed for multi-branch retail operations. It features real-time inventory tracking, seamless branch stock transfers, and detailed analytics for store managers and executives.

## 🚀 Key Features

- 🏪 **Multi-Branch Control**: Transfer stock between main warehouse and branch outlets seamlessly.
- 💵 **Daily Cashier Operations**: Manage daily cash flow, transactions, and custom customer receipts.
- 📊 **Executive Dashboard**: Real-time sales analytics, transaction edit logs, and fine-grained user permissions.
- 💾 **Automated Database Backup**: Built-in automated MySQL database backup system to prevent data loss.
- 📥 **Excel Reports**: Export withdrawal logs and sales reports directly to Excel format.

## 🛠️ Installation & Setup

1. **Clone the Repository** (Private Access Required):
   ```bash
   git clone https://github.com/shetesfa/aleltu.git
   ```
2. **Setup Database**:
   - Open **phpMyAdmin** (`http://localhost/phpmyadmin`).
   - Import the included `database.sql` file.
3. **Configure Application**:
   - Update database credentials in `config.php`.
4. **Launch**: Access via your local server `http://localhost/aleltu/`
